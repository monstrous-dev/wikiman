# Glossary

| Term | Definition |
|------|------------|
| Wikiman | This extension — gives every pi project a living OKF knowledge wiki at `docs/wiki/`. |
| pi | The coding-agent harness this extension plugs into (`pi install git:github.com/monstrous-dev/wikiman`). |
| OKF | Open Knowledge Format — Markdown files with typed frontmatter, `[[wikilinks]]`, and auto-generated indexes; the wiki bundle's format. |
| Wiki bundle | The `docs/wiki/` folder: index, overview, glossary, learnings/rules/decisions/preferences/pages, file-tree, log, `last_updated.md`. |
| Memory digest | Recent decisions/rules/patterns (from `memory.md`) injected into every session's context alongside the nav map and overview. |
| Staleness check | Session-start comparison of code changes vs `docs/wiki/last_updated.md` (git-first, mtime fallback), honoring `.wiki_ignore` + built-in ignores; nudges ask-first. |
| `.wiki_ignore` | Project-root patterns excluded from staleness detection (wiki self-edits, build dirs, lock files). |
| Recap agent (`wiki-recap`) | End-of-turn background sub-agent that mines the turn transcript and records major decisions, rules, and learnings. |
| Curator agent (`wiki-curator`) | Sub-agent that syncs wiki concepts to changed code, classifying real vs ephemeral changes and validating OKF. |
| Sentinel | `<!-- wiki-context:v1 -->` marker ensuring wiki context is injected once per session (re-injected only after compaction/resume). |
| Worktree dormancy | Behavior where the extension reads but never writes inside git linked worktrees — the wiki lives in the main checkout. |
| Viewer | Self-contained `wiki-viewer.html` (generated by `viewer.ts`) that renders the whole bundle in a browser via a localhost server. |
| Agentman | Companion package (`monstrous-dev/agentman`) providing the sub-agent runner the recap/curator agents require. |
